# 🕹️ The Multi-Core Developer

An exciting arcade game-themed website exploring how background coding agents enable developers to parallelize their work and become "multi-core" - just like modern CPUs!

## 🚀 Features

- **Retro Arcade Aesthetics**: Pixel-perfect design with vibrant neon colors and smooth animations
- **Interactive Simulation**: Watch multiple coding agents work in parallel on different tasks
- **Real-time Visualization**: See the power of multi-core development in action
- **Engaging Animations**: Floating shapes, scanline effects, glowing text, and more
- **Responsive Design**: Looks great on all devices

## 🎮 The Multi-Core Developer Concept

Just like modern CPUs with multiple cores processing tasks simultaneously, **multi-core developers** use **background coding agents** to parallelize their work. While you focus on architecture and critical features, autonomous agents handle:

- 🎨 UI/UX implementation
- ✅ Test writing
- 📝 Documentation
- 🔧 Boilerplate code
- 🚀 And much more!

## 🛠️ Tech Stack

- **Next.js 16** - React framework with App Router
- **TypeScript** - Type-safe development
- **Tailwind CSS 4** - Utility-first styling
- **React 19** - Latest React features

## 🏃 Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the arcade magic!

## 🔨 Build

Build the production application:

```bash
npm run build
```

Start the production server:

```bash
npm start
```

## 🎯 Lint

Check code quality:

```bash
npm run lint
```
